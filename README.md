# Acadify Solution organisation profile

The public organisation landing page is maintained in
[profile/README.md](profile/README.md) and displayed at
[github.com/AcadifySolution](https://github.com/AcadifySolution).

## Maintaining the profile

- Describe capabilities supported by the linked repository source.
- Keep project links under the organisation and verify they remain public.
- Distinguish examples, mock behavior, and deployment scaffolding from operating services.
- Do not publish client information, personal account details, invented metrics,
  certifications, office locations, or unverified security guarantees.
- Propose focused changes through a branch and pull request.

Profile content does not establish shared repository policies. Refer to each
project's README, contribution guide, security policy, and license for its terms.
